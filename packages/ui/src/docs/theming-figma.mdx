# Theming in Figma

## Modes

Light and dark are **variable modes** in the Semantic collection. The Primitive collection has no modes, since primitives never change.

<TokenBothThemes name="color-text-primary" />

## Switching mode

Select a frame, open the Variables panel and set the Semantic collection's mode on that frame. Everything inside it, including nested components, follows.

## Components

The library has light and dark versions of every component, driven by the same modes. You do not need to detach or duplicate a component to show it in dark.
