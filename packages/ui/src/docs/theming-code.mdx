# Theming in code

## How the theme is applied

The dark values are scoped to a `data-theme="dark"` attribute. Light values are the default on `:root`, so no attribute is needed for light.

## Switching

```html
<html data-theme="dark">
```

```ts
document.documentElement.dataset.theme = 'dark'; // dark
delete document.documentElement.dataset.theme; // light
```

The attribute can also sit on any element, and everything inside it follows.

## In Storybook

Stories expose a `theme` control (light or dark) that sets the attribute on the story wrapper. There is no global toolbar switch.

## Rule

Components use semantic tokens only. A component that reads a primitive will not change with the theme.
