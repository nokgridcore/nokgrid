# Colour

Colour is defined in two layers. **Primitives** are the raw palette: named steps such as `nokflame-500` that never change between themes. **Semantic** tokens describe a job (`background-surface`, `text-primary`) and point at a different primitive in each theme. Components only ever use semantic tokens.

## Do and don't

<Callout>
**Do** pick the token by the job it does: text on a surface is `text-primary`, not "dark grey".
</Callout>

<Callout>
**Don't** use a primitive (`neutral-900`) in a component. It will not change when the theme does.
</Callout>
